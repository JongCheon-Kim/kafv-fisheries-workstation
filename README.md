## 1. 배포 기준과 설계

- **디자인 MASTER:** `수산정보_워크스테이션_포스터.png` (2026-11-08, 소장님 PASS 승인)
- **사이트 메인:** `index.html` — 추가 서버·빌드 없이 GitHub Pages에서 바로 실행
- **서비스:** 교육교재 3종 + 수산정보 서비스 5종, 총 8종
- **실제 QR:** 승인 이미지에 그려진 모의 QR을 제거하고 8종 URL 인코딩 QR로 대체. 이미지 외부 텍스트 덧씌우기 없음.
- **카드 인터랙션:** 카드 8곳 전체 클릭 가능, 새 탭 이동. 모바일은 8개 전용 반응형 카드로 변경.
- **QR/링크 통합:** `links.json` 기준, 제3차시 `?step=theory` 포함
- **QR 규격:** 4판(L 오류정정, border=4); PC 포스터에 합성, 모바일용은 개별 고해상도 PNG 제공
- **화면 확대·축소:** 가로 포스터 영역은 화면 중심 배치. 작은 화면은 카드형으로 자동 변환.

## 2. GitHub 기존 저장소 교체 방법

1. 기존 저장소 `kafv-fisheries-workstation`의 **main** 브랜치에서 **Add file → Upload files**를 엽니다.
2. 이 ZIP의 압축을 풀고 **내부 파일과 폴더 전체를 저장소 루트**에 업로드합니다.
3. `index.html`, `links.json`, `assets/`, `qr/`, `README.md`, `QA_REPORT.md`가 모두 있어야 합니다.
4. `Commit changes`를 누르고 `Settings → Pages`가 `main → /(root)`인지 확인합니다.
5. 온라인 사이트를 `Ctrl+F5`로 새로고침한 뒤 PC·모바일의 카드·QR을 실제 확인합니다.

**주의:** 새 ZIP에 없는 이전 파일은 GitHub가 자동 삭제하지 않습니다. 본 배포본은 기존 승인본과 같은 저장소를 갱신하는 형식이며, 기존 공개 버전의 복원은 GitHub 커밋 이력을 활용합니다.

## 3. 변경 및 검증 요점

- 예전 HTML에서 이미지의 문자를 가리는 SVG/HTML 문자 레이어는 완전히 제거했습니다.
- 승인한 새 이미지의 픽셀은 QR 대상 영역 8곳을 제외하면 일치합니다.
- 이미지 속 QR, 별도 QR 파일, 실제 카드 링크가 모두 동일 주소를 가리킵니다.
- 브라우저 5종 크기에서 렌더링, 버튼/QR 참조 및 화면 가로 넘침을 검수했습니다.
- 외부 수산 전문 서비스들의 서버 가동과 내부 기능은 이번 로컬 시험의 검증 대상이 아닙니다. GitHub Pages 배포 후 접속 테스트가 필요합니다.
