# KAFV 수산 워크스테이션 v1.0 — GitHub Pages 배포본

- 디자인 MASTER: 사용자 PASS 승인 「수산_워크스테이션_정보_안내판.png」 기반
- 교육교재 3종 + 수산 전문 앱 5종 = 총 8개 카드 및 실제 QR코드
- 포스터 화면: 가로 1120px 이상에서 승인 시안을 그대로 유지하고, 실제 QR코드 8개를 겹쳐 표시
- 모바일 화면: 글자·QR이 읽히는 반응형 카드 8개
- 모든 카드는 클릭 시 해당 서비스의 공개 GitHub Pages 주소를 **새 탭**에서 엽니다.
- QR 인코딩: Python qrcode 라이브러리 / H 오류정정 / URL 문자열 그대로
- 교재·앱의 자체 소스에는 전혀 영향을 주지 않는 독립 정적 허브입니다.

## GitHub 업로드
1. 새 Public 저장소: 제안 `kafv-fisheries-workstation`
2. ZIP을 풀고 `index.html`, `assets/`, `qr/`, `links.json`, README 등을 저장소 **루트**에 업로드
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
4. 배포 후 PC, 휴대전화에서 8개 카드 클릭과 8개 QR 스캔을 확인하고 배포 PASS 판정

## URL과 검증 범위
`links.json`의 8개 URL은 사용자 제공 화면 및 배포 성공 화면을 바탕으로 기록했습니다. 제3~5차시 교재는 사용자 시연으로 열림을 확인했습니다. 수산 전문 앱 5종은 사용자 연구소 링크 목록에서 주소를 확보했으나, 이번 제작 환경에서 **외부 사이트를 직접 열어 확인하는 검수는 제한**되었습니다. 따라서 실제 사용자 브라우저에서 접속 검수를 진행해야 합니다.

## 오류·수정 방지
- 승인 디자인 이미지는 변경하지 않고 사용합니다.
- 사이트 경로는 모두 상대 경로이며 소문자/대문자를 구분합니다.
- 이미지 생성기로 그린 QR 대신 실제 URL을 인코딩한 QR을 사용합니다.
- 주소를 변경할 경우 `links.json`뿐 아니라 `index.html`과 `qr/*.png`를 함께 수정해야 합니다.
- 버전 변경 후 기존 8개 카드·QR 전수 회귀검수합니다.
